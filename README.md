# Рутина

Личный минималистичный трекер рутины под Android. Одно окно со списком дел на сегодня,
кружок для отметки и история выполнения по каждому делу.

## Что умеет

- **Дела со временем и без.** У каждого — название и, если нужно, время напоминания.
  Дела группируются по частям дня: Утро, День, Вечер, Без времени, На паузе.
- **Срок («курс»).** Дело можно завести на определённое число дней — например, 30 —
  или без ограничений. В карточке видно, сколько осталось («осталось 12 из 30 дней»).
  Когда срок выходит, дело само уходит из списка дел вниз, в группу «Завершённые»:
  напоминания прекращаются, а история отметок остаётся. Срок можно поменять в любой
  момент — у существующего дела тоже, продлив курс через «Изменить».
- **Отметка в один тап.** Тап по кружку — отмечено (и наоборот). Сегментный индикатор
  сверху («● ● ○») показывает, всё ли закрыто за день.
- **Напоминания-будильники.** Для дел со временем ставится точный будильник
  (`AlarmManager.setAlarmClock`) — срабатывает минута в минуту и пробивает режим энергосбережения.
  В уведомлении две кнопки: «Сделано» (отмечает без открытия приложения) и «+15 мин».
- **Будильники восстанавливаются сами** после перезагрузки, обновления приложения и смены
  часового пояса.
- **История отметок.** Тап по названию дела открывает: серию (сколько дней подряд),
  статистику за 30 дней, календарную сетку за 60 дней с подписями месяцев и список
  последних отметок.
- **Ничего не прокручивается.** Оба экрана целиком укладываются в экран при любом размере
  окна: дела делят доступную высоту поровну и сжимаются (в тесном режиме время переезжает
  в строку с названием), а календарь сам подбирает размер клетки под свободное место.
  Первый запуск — пустой список, дела добавляются вручную.
- **Приватность.** Всё хранится локально в SQLite (Room) на устройстве. Никакой сети,
  рекламы и аналитики; разрешение на интернет приложению вообще не выдано.
- **Трекер кофеина (по желанию).** Включается в общих настройках (шестерёнка в шапке) — если
  он не нужен, приложение выглядит как раньше. Дневная норма выбирается вручную и
  разбивается на три приёма кратно 50 мг, большие дозы первыми: 250 → 100 + 100 + 50,
  200 → 100 + 50 + 50. Время приёмов считается от подъёма, последний — не позднее чем
  за 8 часов до сна. Норма, время подъёма и сна живут на отдельном экране —
  **настройки трекера** (шестерёнка в шапке экрана кофеина). На самом экране кофеина
  расписания нет — только прогресс, приёмы и таймер. Приёмы отмечаются
  в один тап, ошибочную отметку можно снять тапом по ней.
- **Таймер с настраиваемым интервалом.** На экране кофеина интервал выставляется
  кнопками «−» и «+» шагом 15 минут (от 15 минут до 24 часов). По умолчанию
  подставляется остаток до рекомендованного времени приёма: под кнопками видно
  «следующий приём в 23:00». Рекомендованное время считается от расписания
  (подъём, три приёма, отбой), а после отметок — от фактического времени последнего
  приёма плюс интервал. Таймер сигналит будильником. Внизу — суммы по прошлым дням.
  Автоматических напоминаний о приёмах нет: только таймер, который запускаешь сам.

## Экраны

Главный — список дел на день, «···» в карточке открывает меню: изменить, убрать на паузу,
«Проверить напоминание» (показывает уведомление сразу, чтобы убедиться, что они доходят).
Стрелки ‹ › в шапке — заглянуть в предыдущий день (например, отметить вчерашний приём,
если забыл сразу).

История — статистика и календарь по конкретному делу.

Кофеин — отдельный экран: норма и прогресс, три приёма с временами,
таймер и суммы за прошлые дни. Норма, подъём, сон и разбивка нормы — на экране настроек
трекера (шестерёнка в шапке). В главном списке трекер занимает одну строку
(«Кофеин · 100 из 200 мг»), отметки ставятся внутри экрана кофеина.

## Сборка

```bash
cd /home/artt/Projects/Rutina
export ANDROID_HOME=/home/artt/Android/Sdk JAVA_HOME=/home/artt/.local/jdk/java-17-openjdk
./gradlew testDebugUnitTest assembleDebug   # тесты + debug APK
./gradlew assembleRelease                   # release APK
```

Готовые APK: `dist/Rutina-1.6.apk` (release, подписан собственным ключом),
`dist/Rutina-1.6-debug.apk` (debug-ключ; ставится поверх прошлых debug-сборок)
и `dist/Rutina-1.0-debug.apk`.

**Установка на телефон.** Готовый APK — в разделе Releases:
<https://github.com/arttvad9r/Rutina/releases/latest>. Скачивать файл и открывать
на телефоне напрямую (GitHub отдаёт APK без блокировок). Папка `dist/` в git не
попадает (см. `.gitignore`), поэтому обновлять ассет релиза нужно вручную:
`gh release upload v1.6 dist/Rutina-1.6.apk --clobber`.

**Подпись.** Release подписывается ключом из `keystore/rutina-release.jks`
(пароль — в `keystore/keystore.properties`, папка в `.gitignore` и не попадает в git).
Ключ нужно сохранить: обновления приложения ставятся только поверх APK с той же подписью.
На блокировку скачивания Google подпись не влияет — проверено перекрёстной переподписью
(см. раздел про Drive).

**Google Drive.** Google блокирует скачивание APK, который выглядит как непрофильная
сборка: `403 cannotDownloadAbusiveFile` («identified as malware or spam»). Это не про
подпись и не про rclone — проверено экспериментально. Триггер — содержимое release-APK
без минификации: тот же код, собранный через `assembleDebug`, скачивается, а release
без R8 — нет. Поэтому в `release` включён `isMinifyEnabled = true` (R8): такой APK
качается с Drive напрямую, заодно весит 1.5 МБ вместо 10.8.

Если APK всё же заблокирован: запасной путь — шифрованный архив
(`7z a -tzip -mem=AES256 -p<пароль>`) либо `rclone copy --drive-acknowledge-abuse`
(флаг загрузки на сервере не снимает — он лишь позволяет скачать файл себе).

Установка на телефон по кабелю:

```bash
adb install -r dist/Rutina-1.6.apk
```

Технически: Kotlin 2.1, Jetpack Compose (Material 3), Room, minSdk 26 (Android 8+),
targetSdk/compileSdk 36. Тесты — 56 юнит-тестов: расчёт времени срабатывания, раскладка календаря, подписи
месяцев, сроки курсов, разбивка нормы кофеина на приёмы и рекомендованное время
следующего приёма (56/56 зелёных).

## Разрешения

- `POST_NOTIFICATIONS` — напоминания; приложение попросит его при первом запуске.
- `USE_EXACT_ALARM` — срабатывание ровно в назначенное время.
- `RECEIVE_BOOT_COMPLETED` — восстановление будильников после перезагрузки.

Интернет-разрешения нет намеренно.

## Заметки на будущее

- Настройки уведомлений в MIUI/EMUI/OneUI могут душить будильники: если напоминания
  не приходят, стоит разрешить автозапуск и снять оптимизацию батареи для «Рутины».
- «Проверить напоминание» в меню карточки — самый быстрый способ проверить, что
  система не блокирует уведомления.
