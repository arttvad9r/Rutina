# Импорт и экспорт — проверка версии 1.10

1 октября 2026. Добавлен раздел «Резервная копия» в настройки приложения.
Используются системные CreateDocument/OpenDocument, JSON из Android и транзакция Room;
новые зависимости и разрешения не добавлены. Версия базы остаётся 4.

## Поведение

Экспорт сохраняет привычки, паузу/завершение, сроки, напоминания, отметки с датами,
приёмы кофеина (включая корректировки неотмеченных доз) и настройки модуля.
Формат `rutina-backup`, версия 1, UTF-8 JSON. Запущенный таймер не переносится.

Импорт проверяет формат, версию, связи и значения до изменения базы, показывает
дату копии и число записей, требует подтверждения полной замены. Замена данных
выполняется одной транзакцией; прежние уведомления и будильники отменяются,
напоминания из копии планируются заново. Отменяются и отложенные напоминания.
Лимит импортируемого файла — 10 МБ.

## Автоматические проверки

`./gradlew testDebugUnitTest assembleDebug assembleRelease lintDebug` — успешно.
63 модульных теста, 0 ошибок. Восемь новых тестов проверяют пустые копии,
дубли идентификаторов/дат/слотов, ссылки на отсутствующие привычки, неверные даты,
дозы, настройки, время напоминания и длительность курса.
